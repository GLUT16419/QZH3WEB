ℹ️ 关于

PB_SBC01_H3 路由器管理系统

基于全志H3开发板构建的WiFi路由器，配备功能完善的Web管理界面。

技术特性

  • 🌐 双频WiFi支持 (2.4GHz)
  • 🔐 WPA3/WPA2加密
  • 📊 实时流量监控
  • 🛡️ 防火墙安全保护
  • 🔐 VPN远程访问
  • 📠 实时监控告警
  • ⏰ 定时任务自动化

开发信息

开发时间: 2026年5月

技术栈: HTML5 + CSS3 + JavaScript + C语言CGI

Web服务器: lighttpd

路由器固件: OpenWrt/Debian
